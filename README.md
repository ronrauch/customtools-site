# customtools.app

Public website for CustomTools.App LLC, served by GitHub Pages from `main` (root).

Plain static HTML and CSS. No build step, no dependencies, no analytics, no third-party scripts.

- `/` home
- `/pocket-vj/` Pocket VJ Pro, with `support/` and `privacy/`
- `/live-animation-studio/` support (App Store marketing/support URL) and `privacy` (App Store privacy URL; `privacy.html` and `privacy/index.html` carry the same text so the path works with and without a trailing slash)
- `/red-pen-tools/` Red Pen Tools, with `privacy/`
- `/app-ads.txt` AdMob authorized sellers file (placeholder until the AdMob account exists)

Shared styles live in `assets/site.css`. When the Pocket VJ Pro privacy policy changes, update all three copies.
